# Microsoft Equity Market Analysis

## Project Overview

This project analyses Microsoft Corporation from an equity investor's perspective.

The analysis combines:

- Business and industry analysis
- Financial statement analysis
- Financial ratio analysis
- Historical stock price analysis using Python
- Final investment recommendation (Buy / Hold / Sell)

## Tools Used

- Excel
- Python
  - pandas
  - matplotlib
  - yfinance

## Repository Structure

- `data/` – financial statements and stock data

- `notebooks/` – Python analysis

- `charts/` – figures and visualisations

- `report/` – final equity research report
